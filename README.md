# Personal Portfolio

Welcome to my personal portfolio website, a modern, responsive, and fully functional showcase of my skills and projects.

## Overview

This portfolio is developed using the latest **React.js** framework alongside **Vite** as the build tool for fast and efficient development and bundling. The application uses **HTML**, **CSS**, and **JavaScript** to create a clean, interactive, and visually appealing user experience.

The UI/UX is designed in **Figma**, ensuring a seamless and professional interface. I have also integrated **AI automation** to streamline workflows and enhance performance.

## Key Technologies and Tools Used

- **React.js**: component-based architecture.
- **Vite**: superfast development server and optimized builds.
- **HTML/CSS/JavaScript**: web fundamentals.
- **Figma**: for prototyping and UI design.
- **AI Automation**: to automate and optimize tasks.
- **Git**: version control with effective branching and regular pushes.
  
## Development Workflow

- Version controlled with **Git** using branches for isolated development.
- Code committed and pushed to a private remote repository on GitHub.
- Locally tested thoroughly using `npm run dev`.

## Deployment

The portfolio is hosted on **Vercel**, taking advantage of GitHub integration for automatic deployment on every push to the main branch. This keeps the live site always current.
